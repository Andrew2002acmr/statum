- Использовать семантические области: `header`, `main`, `section`, `footer`, `nav`. `[Рекомендация]`
- На странице должен быть один понятный `h1` и логичная иерархия заголовков. `[Рекомендация]`
- Поля формы должны иметь настоящие `label`, а не только placeholder. `[Рекомендация]`
