# TECH-STACK

## Статус

Технический стек зафиксирован до начала реализации. На этом этапе приложение не инициализируется, зависимости не устанавливаются, реализация не начинается.

## Основа

- Astro.
- TypeScript в strict-режиме.
- Astro Components для секций страницы.
- Обычный TypeScript для простой клиентской интерактивности.

## Стили

- Tailwind CSS.
- CSS custom properties для цветов, размеров контейнера, отступов, скруглений, теней и других дизайн-токенов.
- Scoped CSS допускается для сложных отдельных секций.
- Готовую UI-библиотеку не использовать.

## Интерактивность

- Мобильное меню, модальные окна и простые элементы реализовывать без отдельного frontend-фреймворка.
- React, Preact или Vue не добавлять без отдельного обоснования и согласования с владельцем проекта.
- Для простого слайдера предпочтительно использовать CSS Scroll Snap и TypeScript.
- Библиотеку слайдера подключать только при наличии функциональной необходимости.

## Форма

- Astro Actions.
- Zod для серверной валидации.
- Предусмотреть состояния `loading`, `success` и `error`.
- Предусмотреть honeypot и возможность подключения Cloudflare Turnstile.
- Конкретный способ доставки заявки пока `TBD`: email, Telegram или CRM.
- До подключения реального обработчика не показывать пользователю ложное сообщение об успешной отправке.

## Иконки

- Использовать Lucide.
- Не смешивать несколько библиотек иконок.
- Логотип и уникальную графику хранить как отдельные SVG.

## Изображения

- На первом этапе разрешены локальные заглушки.
- Заглушки должны иметь правильные пропорции будущих изображений.
- Контент не должен зависеть от конкретных размеров временных изображений.
- Предусмотреть последующую замену изображений без изменения структуры компонентов.
- Использовать компоненты Astro Image/Picture после появления оригиналов.
- Для изображений указывать размеры, чтобы исключить скачки макета.

## Проверки

- `astro check`.
- ESLint.
- Prettier.
- Playwright для проверки страницы в браузере.
- Контрольные размеры: 1440, 1024, 768 и 390 px.
- Проверять отсутствие горизонтального скролла и наложения элементов.

## Развертывание

- Node.js.
- Docker.
- nginx.
- GitHub Actions.
- Astro Node adapter потребуется, если форма будет обрабатываться внутри Astro-приложения.

## Не добавлять без отдельного согласования

- Next.js.
- Отдельное React-приложение.
- NestJS или Express.
- PostgreSQL и другие базы данных.
- Redis.
- Redux.
- Готовую UI-библиотеку.
- Несколько библиотек иконок.
- Тяжелую библиотеку анимаций.
