## Этап 5 - Форма и обработка заявки

Задачи:

- Реализовать форму через Astro Actions. `[Рекомендация]`
- Описать серверную схему валидации через Zod. `[Рекомендация]`

Результат:

- Форма доступна, валидируется и готова к подключению реальной доставки заявки.

Проверка:

- Невалидные данные блокируются Zod-схемой.
- Ошибка отправки отображается без потери данных.
- Форма проходит keyboard-only сценарий.
- До реального обработчика success не имитируется.
